# Proyecto Web Canaco

Este es un proyecto web desarrollado con **Django** en Python. Es una plataforma diseñada para administrar contenido como noticias, categorías de publicaciones, usuarios y comentarios.

---

## ¿Qué se realizó en este proyecto?

1. **Configuración Inicial y Estructura:**
   - Creación del proyecto principal en Django (`canaco`) y de la aplicación principal (`home`).
     
2. **Control de Rutas y Vistas:**
   - Enlace de URLs (`urls.py`) con sus respectivas funciones en las vistas (`views.py`) para renderizar cada pantalla.

3. **Diseño de Plantillas HTML:**
   - Creación de una plantilla general reutilizable (`base.html`) y componentes parciales (`partials`).
   - Maquetación de pantallas públicas: Inicio, Contáctanos, Noticias y Categorías.
   - Maquetación de la sección de acceso: Login y Registro de usuarios.
   - Creación de interfaces de administración (**CRUD**) para gestionar usuarios, categorías, noticias, comentarios y perfil de usuario.

4. **Archivos Estáticos:**
   - Organización de carpetas para los archivos de diseño visual (`css`), tipografías (`fonts`), imágenes (`images`) y scripts (`js`).

---

## Tecnologías Utilizadas

- **Python** & **Django 4.2**
- **HTML5**, **CSS3** y **JavaScript**
- **Git** & **GitHub**
